Titipin API (0.1.0)

Download OpenAPI specification:

Titipin adalah platform yang menyediakan layanan titip barang dari luar negeri ke Indonesia. All monetary amounts are integers in the minor unit of the stated currency. Clients MUST ignore unknown response fields.

Requests

Item requests created by requesters.

List item requests

Returns a paginated collection of requests visible to the authenticated account. The optional status filter only narrows the same resource type. Results are never unbounded. An MCP operations client may read this collection but may not use it to perform a consequential action.

query Parameters
status
string
Enum: "open" "assigned" "completed" "expired" "cancelled" "unavailable"
Example: status=open

Filters requests by one known status.

limit
integer [ 1 .. 100 ]
Default: 20
Example: limit=10

Maximum number of items to return. The service applies a default and an upper bound.

cursor
string <= 512 characters
Example: cursor=eyJvZmZzZXQiOjEwfQ

Opaque cursor returned by the previous page.

Create an item request

Creates one request for an item, target store or area, budget, delivery address, and deadline. The requester identity comes from the access token. This unsafe operation requires Idempotency-Key.

header Parameters
Idempotency-Key
required
string <uuid> ^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-4[0-9a-fA-F]{3...
Example: 0f7c1b9e-3d21-4a6f-9c05-8e2b7d41a9f0

Canonical hyphenated UUID version 4. Generate it when the user confirms the action and reuse it unchanged with the same method, URI, and body for every retry of that intent. The service retains the key and stored result for 24 hours from first receipt. Reuse with a different request returns 409 idempotency-key-reuse. An identical request still in progress returns 409 with Retry-After.

Request Body schema: application/json
required

Human-readable description of the requested item.

required

Maximum budget for the requested purchase.

required
string [ 1 .. 500 ] characters

Address where the item should be delivered.

required
